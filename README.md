# Muhammad Hassan — Portfolio

A React and Vite portfolio website.

## Run locally

```cmd
npm ci
npm run dev
```

Open the local URL printed by Vite, usually `http://localhost:5173/`.

## Publish with GitHub Pages

Push the `main` branch to GitHub. The workflow in `.github/workflows/deploy.yml` builds the site and deploys it to GitHub Pages. In the repository, open **Settings → Pages** and set the build and deployment source to **GitHub Actions**.

The build automatically uses the repository path, so the public videos, images, and CV downloads work for either a project site or a user site.
